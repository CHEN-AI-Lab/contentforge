# ContentForge 内容熔炉

> AI 多平台内容改编工具。一键生成小红书、公众号、微博、抖音口播、视频号、B 站与 SEO 标题包。

## 一句话

**一篇长文，全网分发。**

你写一次母版，ContentForge 自动按 7 大平台的规则改编成适合各平台的版本。不用再改七遍稿。

## 适合谁

- **独立创作者** — 每周 1 篇深度文，熔炼成全平台内容
- **知识博主** — 把课程/文章改编成短视频口播
- **品牌运营** — 一份产品文档，生成所有平台的推广文案
- **MCN 机构** — 批量处理旗下账号的内容需求

## 核心功能

| 平台 | 产出 | 说明 |
|------|------|------|
| 📕 小红书 | 种草笔记 | Emoji + 清单体 + 互动结尾 |
| 💬 公众号 | 推文结构 | 摘要 + 分级标题 + 文末引导 |
| 🔥 微博 | 短文案 | 280 字内 + #话题# |
| 🎬 抖音 | 分镜口播 | 45-60 秒脚本 + 分段时间轴 |
| 📹 视频号 | 发布包 | 标题 + 描述 + 90 秒口播 |
| 📺 B 站 | 投稿包 | 标题 + 简介 + 3-5 分钟脚本 |
| 🔍 SEO | 标题包 | 搜索标题 + Meta 描述 + 关键词 |

## 三种语气

- **轻松口语** — 像跟朋友聊天
- **专业可信** — 适合 B2B、知识类
- **爆款吸睛** — 强钩子、短句、情绪词

## 为什么需要这个工具

做自媒体最耗时的不是写作，而是**同一篇文章要改五遍**：

- 小红书要 emoji 和清单体
- 公众号要结构化和小标题
- 微博要压缩到 280 字
- 抖音要口播感和分镜脚本
- 视频号要偏私域的正式语气
- B 站要年轻化的表达方式
- SEO 要关键词和 Meta 描述

ContentForge 的思路很简单：**你只写一次「母版」长文，系统自动按平台规则改编。**

实测能省下 70% 以上的分发时间。

## 三步开始

1. **写母版** — 每周一篇 1500 字深度文（公众号/博客）
2. **熔炼分发** — 用 ContentForge 生成全平台版本并定时发布
3. **导流变现** — 简介挂课程/社群/联盟链接，专业版订阅回本

## 技术说明

- **前端**: Next.js 15 (App Router), Tailwind CSS, TypeScript
- **后端**: 无（纯前端规则引擎，API 路由运行在 Next.js 中）
- **存储**: localStorage（无需数据库）
- **部署**: 本地运行或 Vercel 一键部署
