# Pages.md — 页面规格

## 页面清单

| 路径 | 页面 | 类型 |
|------|------|------|
| `/` | 首页 | 落地页 |
| `/tool` | 内容改编工具 | 核心功能 |
| `/pricing` | 定价 | 转化页 |
| `/blog` | 博客列表 | 内容营销 |
| `/blog/[slug]` | 博客文章详情 | 内容营销 |
| `/about` | 关于我们 | 品牌页 |
| `/api/repurpose` | API 路由 | 后端逻辑 |

│                                         │
│  [开始免费使用 →]                        │
│                                         │
├─────────────────────────────────────────┤
│  支持的平台：                            │
│  📕 小红书  💬 公众号  🔥 微博           │

│  └────────────────────────────────────┘  │
│                                          │
│  选择目标平台：                           │
│  ☑ 小红书  ☑ 公众号  ☑ 微博             │
│  ☐ 抖音    ☐ 视频号  ☐ B 站   ☐ SEO      │

│  选择语气：                               │

│  │                                    │  │
│  │ #AI工具 #内容创作 #效率神器          │  │
│  └────────────────────────────────────┘  │
│  [复制]                                  │
│                                          │
│  💬 公众号                               │
│  ┌────────────────────────────────────┐  │
│  │ 摘要：...                           │  │
│  │ ## 标题                             │  │
│  │ 正文内容...                         │  │

### 交互逻辑
1. 用户粘贴内容 → 自动检测字数
2. 选择平台（可多选）
3. 选择语气（单选，默认轻松口语）
4. 点击生成 → 检查使用限额 → 调用 `repurpose()` 引擎 → 显示结果
5. 每个结果有「复制」按钮

## `/blog` — 博客列表

### 目标
- SEO 内容营销，吸引搜索流量

### 结构
- 文章列表（标题、摘要、日期、标签）

## `/blog/[slug]` — 博客文章详情

### 目标
