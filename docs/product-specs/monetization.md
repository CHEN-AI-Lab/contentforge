# Monetization.md — 变现策略

## 商业模式概述

ContentForge 采用 **Freemium 订阅制**，参考 Castmagic、Repurpose.io 等已验证的 Micro-SaaS 路径。

## 定价档位

| 档位 | 价格 | 额度 | 目标用户 |
|------|------|------|---------|
| 免费版 | ¥0 | 每日 5 次 | 个人创作者试用 |
| 专业版 | ¥29/月 | 每月 200 次 | 全职创作者 |
| 团队版 | ¥99/月 | 每月 1000 次 + 5 席位 | MCN/小团队 |

## 定价逻辑

### 免费版（¥0/日 5 次）
- **目的**: 降低使用门槛，让用户体验核心价值
- **限制**: 每日重置，无法保存偏好，无历史记录
- **转化点**: 用户看到生成效果后，自然有升级需求

### 专业版（¥29/月）
- **定位**: 全职内容创作者的核心生产力工具
- **价值**: 200 次 ≈ 每周 50 次 ≈ 每天 7 次（可覆盖多平台）
- **对标**: 比剪映会员（¥25/月）略贵，但解决的是更刚需的内容改编问题
- **锚定**: 用户算一笔账——省下的 2 小时/周 × 时薪 > ¥29

### 团队版（¥99/月）
- **定位**: MCN 机构、品牌内容团队
- **价值**: 1000 次 + 5 席位，人均 200 次
- **锚定**: 外包一次内容改编 ¥200-500，团队版相当于 2-5 次外包的价格

## 支付方案

### 推荐方案
- **微信/支付宝扫码支付** — 国内用户最熟悉
- **手动激活码** — 用户支付后，管理员在后台发放激活码
- **无需后端** — 激活码存储在 localStorage，验证逻辑在前端

### 可选方案
- **Stripe** — 如果面向海外用户
- **Paddle** — 处理全球支付 + 税务

## 转化路径

```
用户访问 → 免费试用 → 看到效果 → 遇到限额 → 弹出升级 → 支付 → 激活
```

### 关键转化点

1. **首次生成后** — 展示「生成效果很好，专业版每月 200 次，¥29」
2. **达到限额时** — 明确提示「今日次数已用完，升级专业版解锁更多」
3. **使用偏好保存时** — 「保存偏好需要专业版，每月 ¥29」

## 增长策略

1. **内容营销** — 在小红书/公众号发布「如何用 ContentForge 节省 80% 改编时间」
2. **SEO** — 优化「内容改编工具」「AI 多平台文案」等关键词
3. **口碑传播** — 免费版用户生成后，分享链接可额外获得 5 次
4. **B 端拓展** — 主动联系 MCN 机构，提供团队版试用

## 风险提示

- **AI 同质化** — 竞品可能快速复制功能 → 靠社区和口碑建立壁垒
- **平台规则变化** — 小红书/抖音等平台规则调整 → 快速迭代适配
- **支付合规** — 手动激活码模式需确保合规 → 建议接入正规支付渠道
